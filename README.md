# WordPress 開発環境(devcontainer)

WordPress 7.x(公式イメージ `wordpress:php8.5-apache`)

## 使い方

1. VS Codeで開き「Reopen in Container」
2. 初回起動時にWordPressがインストールされる

| 用途 | URL |
|---|---|
| サイト | http://localhost:8080 |
| 管理画面 | http://localhost:8080/wp-admin (admin / admin) |
| メール確認 (Mailpit) | http://localhost:8025 |
